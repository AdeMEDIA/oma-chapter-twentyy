INSTALL
1. Back up your existing src folder.
2. Extract this ZIP into a temporary folder.
3. Copy the enclosed src folder into C:\Users\user\Projects\oma-chapter-twenty.
   Replace matching files. Keep main.jsx unchanged.
4. Copy the enclosed public folder into the SAME project folder.
   Merge folders. Do not remove your existing images/audio/video folders.
   This adds public/images/room/birthday-room.webp, which is required for the room.
5. If your server is running, refresh. Otherwise run npm.cmd run dev.
6. Open the Local URL. The room is now the homepage, including with no URL hash.
   If an old hash is present, click the OMA wordmark or use /#/room.
7. No new npm packages are required.
